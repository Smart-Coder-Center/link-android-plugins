# Magic Touch runtime package

The Magic Touch Photo plugin is assembled as one signed ARM64 ZIP. The APK contains only the trusted
runtime verifier/loader and the feature integration; the ZIP contains the MediaPipe Tasks Java runtime
compiled to DEX, every resolved ARM64 native library, the MagicTouch `.task` model, and provenance/license
files.

## Pinned build inputs

- MediaPipe Tasks Vision: `com.google.mediapipe:tasks-vision:1.1.1`
- MagicTouch model: the immutable Google Storage object under `magic_touch/int8/1/`
- Android D8: Android build-tools `35.0.0`, minimum DEX API 24
- Gradle dependency resolver: `8.14.4`
- Target ABI: `arm64-v8a`

The build resolves the complete Maven runtime graph from Google Maven and Maven Central, extracts every
AAR `classes.jar` and every `jni/arm64-v8a/*.so`, compiles the Link adapter against those APIs, then
runs D8 to produce DEX. Native library dependencies are read from ELF DT_NEEDED and topologically
ordered dependency-first. Unresolved non-system dependencies and conflicting library filenames fail
the build.

## First-run checksum audit

The first build must not sign upstream bytes before their exact hashes have been reviewed and pinned.

1. Open Actions → **Audit Magic Touch runtime dependencies**.
2. Run workflow on `main`.
3. Inspect the generated `magic-touch-runtime-audit` artifact and the workflow summary.
4. Review and commit the generated checksum JSON as `tools/mediapipe-runtime.lock.json`.
5. The regular **Package and publish universal Link plugins** workflow refuses to package Magic Touch
   unless every downloaded Maven artifact and the model match this committed SHA-256 lock.

The audit workflow does not publish a release or update the public catalog.

## Package contents

- `model/interactive_segmentation.task`
- `code/classes*.dex` (all D8 output shards)
- `lib/arm64-v8a/*.so` (all resolved native runtime libraries)
- `provenance/mediapipe-runtime-lock.json`
- `LICENSE-MEDIAPIPE` and `NOTICE`
- signed `plugin.json` and `plugin.json.sig` generated by the publisher

## Runtime contract

The entry class is `eu.siacs.link.plugins.magic_touch.MagicTouchPlugin`. Its static factory accepts
`create(Context, File)`. The returned object exposes `setImage(Bitmap)`,
`segment(float[] x, float[] y, int[] mode)`, `getMaskWidth()`, `getMaskHeight()`, and `close()`.
Brush mode 0 means positive/foreground and 1 means negative/background.

The package targets Android API 24+ for MediaPipe; Link's existing Ed25519 runtime verifier currently
requires Android API 28+. This does not change Link's minSdk. The feature must remain unavailable on
devices below the runtime verifier's supported API level.

DEX loading is publisher-trust, not sandboxing: plugin code executes with Link's UID and permissions.
Only first-party packages signed by Link's pinned Ed25519 key may contain DEX/JAR files.
